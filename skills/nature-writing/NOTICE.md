## Verbatim quotations

The files under `skills/nature-writing/extracts/` contain short verbatim
quotations from open-access papers. Copyright remains with the original authors
and publishers. The quotations are included for academic commentary and writing
education.

Open access is not the same as public domain. Papers use different licenses
(such as CC BY, CC BY-NC, or publisher-specific terms). Check the license of each
source before redistributing a quotation collection or using it commercially.

## Corpus references

The corpus table in the README and `SKILL.md` lists paper titles, authors, and
venues for identification and citation. It does not transfer any rights.

## Upstream project

This repository packages the local v5 version of the
[nature-writing-skill](https://github.com/SyntaxSmith/nature-writing-skill)
project for cross-agent use. The writing protocol and corpus belong to the
original project and the paper authors.

## Takedown requests

If you are a rights holder and believe a quotation exceeds your license or fair
use, please open an issue with the file and passage. It will be reviewed and,
where appropriate, removed or replaced with a citation.
